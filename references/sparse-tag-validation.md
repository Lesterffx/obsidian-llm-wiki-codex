# 文末增强的稀疏标签验收

本说明验证 `enhance-wiki-content` 的窄例外，不是新的自动打标程序。语义标签仍由执行 Skill 的 agent 根据目标 Schema 和允许的页面证据判断；既有索引/队列测试不证明模型的实际选标签质量。下列资料均为虚构，不依赖真实 Wiki、raw 或账号。

## 固定示例与触发条件

假设示例 Schema 明确允许 `type/知识`、`domain/示例`、`topic/任务`、`topic/工具`。虚构页面明确讨论任务分解和工具调用，候选依此为四个标签，按类型、领域、主题顺序追加。这是验收夹具，不是 Skill 的全局标签默认值。冻结执行日期为 `2030-01-02`，原 `updated` 为 `2030-01-01`。

| 原始 tags | 预期结果 | updated / 边界 |
|---|---|---|
| 字段缺失 | 新增上述四个标签 | 日期改为执行日；其他缺失标准字段仍按原规则补齐 |
| `[]` | 增加上述四个标签 | 日期改为执行日 |
| YAML null / 空值 | 增加上述四个标签 | 只改 tags 容器及日期 |
| `[clippings]` | clippings 在前，追加四个标签 | 日期改为执行日，不删除剪藏标签 |
| `[topic/任务]` | 保留该标签在前，追加类型、领域和 topic/工具 | 不重复追加已有主题 |
| `[clippings, clippings]` | 原两个 clippings 不变，再追加四个标签 | 去重后只有一个，仍触发；不清理旧重复 |
| `[clippings, topic/任务]` | 原 tags 不变 | 两个有效标签，不触发；保留旧日期 |
| 单个安全字符串 `"clippings"` | 改为列表，保留原字符串字面值作首项，再追加 | 不重新序列化其他字段 |
| 含空字符串的安全列表 | 保留旧项，只按非空有效字符串去重计数 | 不用空项规避触发，不擅自清理 |
| 列表包含数值/对象，或 tags 为 mapping | 整项零写入 | 不修改正文、日期、索引、日志或队列 |
| 不完整 YAML 或重复元数据键 | 整项零写入 | 不增加第二个 frontmatter |
| 已补齐页面再次运行 | 不再追加标签 | 既有日期保持，无新内容/维护动作时零写入、无日志/队列 |
| 明确只读或禁止修改元数据 | 只报告稀疏标签 | 所有文件不变 |
| 无法确定主题 | 只增加 Schema/资料可支持的标签，报告不足 | 不为达到三标签目标虚构内容；无新增标签则保留日期 |

## 保留验证

对 LF 和 CRLF、带/不带末尾换行的虚构输入分别检查：

1. 写前保存原文件字节、frontmatter 范围、tags/updated 范围、媒体位置和哈希；已有标题、作者、自定义字段、来源、标签顺序和注释都应保留。
2. tags 为列表时仅插入新项；安全 scalar/空容器只改其必要范围。无法保留 comments 或容器语法时停止写入。
3. 原文含 `![[sample.png|320]]` 和 `![[sample.mp4]]` 时，两种命令形式都保留引用和顺序；单参数仍不打开媒体或读取 raw。
4. 有独立 `标签：#clippings` 区时，仅在已确认的区内追加新标签；不创建新标签区。普通 prose、代码、引用、comments 内的 hashtags 保持。
5. 逐一撤销记录的 tags/updated 修改和独立 inline 插入，再移除新增 EOF 区；重建的原文件必须与写前哈希相同。没有 inline 插入时，原正文必须仍为完整字节前缀。
6. 即使已有六类总结且无新增正文，标签补齐仍可独立执行；没有新增标签时，仅正文增强不得改变既有 updated。

## 索引与 defer/sync

- **已收录且实际新增标签**：只同步唯一对应行的标签列；链接、摘要、分区和其他页面条目不变。刷新维护说明、六变量和页脚，`footer_match=true`；页面数通常不变。
- **已收录但未新增标签**：索引保持，既有统计漂移只报告。不得把本规则扩展成每次重写摘要或全库标签。
- **未收录**：仍只能向合适的既有分区补录目标页。分区不明时报告；不新建结构或补录无关页。
- **重复/歧义或标签列不可安全修改**：保留索引，报告联动未完成；不得任意挑一条覆盖。
- **defer**：仅写页面和现有 queue v1 片段；已有索引需同步标签时，summary 为 `tag-sync | 稀疏标签补齐`，index-entry 保留原链接/摘要并携带最终标签，log-entry 记录原标签、新增标签、原索引标签列和日期。共享 index/log/Schema 保持。
- **sync**：先核对页面快照和原标签、新增标签、现条目与片段的链接/摘要/分区及最终标签，标签列已匹配时视为收敛；否则核对原索引标签列未变后才最小更新。冲突片段保留报告；无标识或未记录实际新增标签的 enhance 片段，已有索引只验证。
- **零变更**：不追加日志、不刷新日期、不入队。日志变化时保留历史字节前缀，并核对完整唯一追加记录。
