# Wiki 页面路径与目录批量处理：规则与虚构验收案例

仅适用于 `enhance-wiki-content` 和 `update-raw-reference`。这是将目录展开为单页 Skill 工作流的规则，不是新的 shell 命令、执行程序或参数。文件输入保持原有行为；目录输入只改变任务分派，不扩大单页的修改权限。

## 第一参数识别（含省略 `.md`）

两个命令共用以下识别顺序，先确定第一参数是单页还是目录，再考虑 raw 配对：

1. 先校验参数数量与标志。保留输入是否带末尾 `/` 或 `\` 的信息；解析 vault 相对路径、规范化 `..`，检查 Wiki 边界及符号链接/junction 的真实路径。
2. 检查原路径。有效 `.md` 文件按单页处理；有效目录按目录处理，即使为空或旁边存在同名 `.md` 文件也保持目录模式。已有其他类型文件、损坏链接、访问失败或越界属于错误，不得转为后缀补全。
3. 仅当原路径确实不存在、未以 `.md` 结尾（扩展名不区分大小写），且输入没有明确的末尾目录分隔符时，尝试原路径直接追加 `.md`。只查这一同级候选，不替换已有后缀、不模糊匹配、不跨目录搜索，也不尝试 `.md.md`。候选必须唯一存在、是有效 Markdown 文件，且原路径和候选真实路径均满足 vault/Wiki 边界。
4. 候选通过后直接按单页继续，无需用户补后缀或再次确认；简述输入已对应到的实际文件。候选不存在、类型错误、歧义、链接损坏、访问失败或越界时，才按原规则零写入停止。不得创建目标或改变原命令的 frontmatter、写入、日志及无操作规则。
5. 单页模式的第二参数始终是该页的直接 raw 来源，不额外拼接页面名；raw 目录可以无子目录，也可以有子目录，其结构不决定第一参数模式。第二参数自身仍须是既有、安全的 raw 目录，不补后缀或另找来源。只有第一参数确认为目录时，才使用下节的直属同名 raw 子目录配对规则；单参数 enhancement 保持仅正文模式。

例如下列省略后缀调用，在 `wiki/演示/复盘.md` 存在而 `wiki/演示/复盘` 不存在时，均对应单页 `复盘.md`，直接使用 `raw/演示/素材/`（无需其中还有子目录）：

```text
$obsidian-llm-wiki enhance-wiki-content "wiki/演示/复盘" "raw/演示/素材/"
$obsidian-llm-wiki update-raw-reference "wiki/演示/复盘" "raw/演示/素材/"
```

## 输入与匹配

```text
$obsidian-llm-wiki enhance-wiki-content "wiki/<领域>/<章节>/" ["raw/<领域>/<章节>/"]
$obsidian-llm-wiki update-raw-reference "wiki/<领域>/<章节>/" "raw/<领域>/<章节>/"
```

- enhancement 接受一或两个位置参数；reference repair 必须两个。保留原有标志校验：enhancement 的 `--defer`、`--no-video` 可任意顺序位于路径之前；reference repair 只接受 `--defer`，不能因目录模式新增 `--no-video`。
- 第一参数按上述识别规则得到的有效目标必须是当前 vault 的 `wiki/` 内既有 `.md` 文件或目录；若提供第二参数，它必须是 `raw/` 内既有目录。允许的后缀补全仍未找到目标、类型错误、未知/重复/错位标志及越界都导致整批零写入。不得创建输入页面或来源目录。
- 第一参数为文件时，第二参数就是该页的显式来源；页面与来源目录可以不同名，不额外拼接子目录。省略第二参数的 enhancement 始终仅使用本页文字。
- 第一参数为目录时，只枚举直属普通文件及可安全解析的文件链接，扩展名按大小写不敏感的 `.md` 识别；不进入子目录或目录链接，不处理同目录其他文件。将数字段按整数比较，其余字符按原字符序比较；自然排序键相同时以完整原文件名作稳定排序。固定这份清单，运行中新出现的文件留到下次调用。
- raw 配对只查第二参数目录的直属条目：目录名必须逐字等于页面文件名去掉末尾 `.md` 后的名称，保留空格、大小写、标点及 Unicode 形式；不做编号匹配、模糊匹配或顺序配对。Wiki 根目录与 raw 根目录本身不必同名。
- 同名 raw 子目录缺失时，enhancement 的有效子任务等价于 `enhance-wiki-content "该页.md"`，仅使用本页正文，仍须按标准标题补齐六节；只缩小证据范围，不跳过页面，也不缩减为只补关联导航。reference repair 则整页跳过，连 frontmatter、日期、索引、日志、队列都不改。无第二参数的目录 enhancement 中，每篇都采用单参数模式。不查 frontmatter `sources` 的内容、不读取媒体，也不把根目录、其他子目录或其他页面作为替代来源；沿用单参数对既有来源存在性的有限验证许可。
- 区分“缺失”与“错误”：同名条目是文件、损坏链接、真实路径越界或不能唯一确定时属于预检失败，不能伪装成缺失后降级。顶层 raw 根目录不存在也不能降级。

## 每页六节完成标准

单页与批量、有 raw 与无 raw 的 enhancement 均以真实二级标题检查 `资料总结`、`洞见`、`方法论提炼`、`最佳实践`、`金句精选`、`关联 Wiki`。正文已有概念、对比、方法、实践或结论，不等于已有对应标准章节；应将这些内容作为依据，在 EOF 按上述顺序归纳补齐缺节。

已有同名标准章节及内容不重复追加、不移动、不改写；代码、引用、转义示例和注释中的标题不计入。缺节证据不足时，在该标准标题下简述限制。六节齐全且没有其他必要维护时才是无操作，不新增边界说明、日期、日志或队列。逐页记录已有/新增章节及证据限制，不能仅凭主题相近宣称六节完整。

## 预检、执行与收尾

1. 先读取 Schema 和 index，在内存建立固定的逐页分派表：序号、Wiki 路径、raw 候选、有效来源/模式、预检状态。记录每页原始路径与解析后的目标身份。原始路径及真实路径都必须在 vault 和各自 wiki/raw 边界内；选中页面及 raw 子目录解析后还必须处于各自输入根目录内。两个清单条目不得指向同一真实页面。
2. 写入前验证所有选中页面的路径，以及所有将执行页面的完整内容和 frontmatter；按各命令规则判断缺失字段可修复、不安全 YAML 必须拒绝。reference repair 缺失 raw 的跳过页不执行内容/元数据修复。任何顶层或整批预检错误都使整个批次零写入，包括页面、共享文件、日志、队列、预处理与临时产物；不能先修改前几页，再发现后页 frontmatter 不安全。空清单为无操作，不刷新日期、索引或日志。
3. 预检通过后，按固定顺序串行调用原单页规则。使用每页的**有效参数**决定来源、缺失 sources、稀疏标签和视频权限；原调用有两个参数不代表降级页可以读 raw。`--no-video` 继续跳过视频及附属字幕；不得自动开启 defer、sync、子 agent 或并行。
4. 每页写入前重新核对目标路径、来源范围与哈希，沿用并发干扰检查；不替换已固定的页面/来源身份。执行中才出现的单页冲突、读取失败或不可用证据按原命令安全停止该页，报告是否已有部分变更或收尾未完成，再继续其余安全页面。保留之前成功结果，不声称具备跨页原子回滚。
5. 正文、媒体顺序、frontmatter 窄例外、索引权限、raw 只读、换行与日志历史前缀验证均沿用单页规则。普通模式每个实际变化页面完成其原有索引/日志收尾；defer 模式每个变化页面或待处理索引动作写自己的片段，不改共享文件。跳过页与无变化页不生成片段、日期或日志；不追加额外的批次日志，也不自动 sync。
6. 最终按同一清单逐页报告有效来源/模式、已变更、无变化、缺失 raw 跳过、预检阻断或执行失败，以及未完成的收尾；嵌套目录只作为排除项说明。区分成功、跳过与失败总数，不能将部分失败表述为整批成功。真实清单、路径、文件名、匹配结果和跳过原因都属于私人运行资料，只留在当前任务或已授权的私有产物中。

## 虚构示例

```text
wiki/演示/练习/
  1 引言.md
  2 闭环.md
  10 总结.md
  嵌套/3 深层.md
raw/演示/练习/
  1 其他/
  2 闭环/
  10 总结/
```

目录 enhancement 展开为下列有效子任务，标志原样传递；reference repair 使用相同的选页/配对规则，但第一行整页跳过。

| 顺序 | Wiki 页面 | enhancement 的有效 raw | 行为 |
|---:|---|---|---|
| 1 | `wiki/演示/练习/1 引言.md` | 无 | 等价于单参数单页调用，仅用正文补齐标准六节，不能改用 `1 其他/` |
| 2 | `wiki/演示/练习/2 闭环.md` | `raw/演示/练习/2 闭环/` | 沿用双参数单页规则 |
| 3 | `wiki/演示/练习/10 总结.md` | `raw/演示/练习/10 总结/` | 沿用双参数单页规则 |

`嵌套/3 深层.md` 不在清单内；raw 根目录不作为任何页面的候补来源。示例不能作为读取真实课程、重跑已完成页面或公开真实材料的授权。

## 验收场景

以下是验收预期，不是自动测试通过记录。使用虚构目录或只读场景检查，真实知识库不得作为公开 fixture；不要为了测试新增执行程序或复制整套分派实现。

| 场景 | 必须观察到的结果 |
|---|---|
| 两命令省略 `.md`，原路径不存在、同名文件存在，raw 无子目录 | 均按单页处理并直接使用给定 raw；无需用户补后缀、无需同名 raw 子目录 |
| 单参数 enhancement 省略 `.md` | 对应同名 Markdown 文件后保持仅正文模式，不读取 raw/媒体 |
| 原路径是目录，同时存在同名 `.md` | 目录优先；包括空目录无操作，不转为同名文件 |
| 原路径不存在且输入末尾为 `/` 或 `\` | 保留明确目录意图，不去掉分隔符尝试 `.md`，零写入停止 |
| 显式 `.md` / `.MD` 路径不存在，但存在追加 `.md` 的文件 | 不尝试 `.md.md` 或 `.MD.md`，零写入停止 |
| 省略后缀的候选也不存在、是目录或不能唯一确定 | 零写入停止，不创建文件、不另找相似页面 |
| 原路径或候选为错误类型、损坏链接、访问失败或真实路径越界 | 仍属预检错误，不当作普通缺失补全或绕过 |
| 省略后缀同时有非法标志，或对应页面 frontmatter 不安全 | 参数或页面预检照常阻断，零写入，包括日志、队列与临时产物 |
| 上方目录与 `2/10` 顺序 | 仅 3 篇，顺序 1、2、10；嵌套页面排除 |
| 同名子目录与只有编号相同的目录 | 只匹配完整同名；`1 其他/` 不对应 `1 引言.md` |
| 中文、空格、标点、大小写不同 | 精确保留名称；不清洗、折叠或模糊匹配 |
| enhancement 缺失某个 raw 子目录 | 该页等价于单参数单页调用，仅正文补齐缺少的标准章节，不只补关联；其他页继续使用各自 raw |
| repair 缺失某个 raw 子目录 | 该页所有文件零修改，其他页继续；不能补索引或日志 |
| 单参数目录 enhancement | 所有直属页面正文模式，采用同一六节标准，不回查其他 raw/媒体 |
| 单文件加不同名 raw 目录 | 保留原有直接配对，不拼接页面名 |
| 空目录、全部 repair 配对缺失 | 零写入，不建队列或运行日志预检 |
| 顶层 raw 缺失、同名条目不是目录 | 整批预检拒绝，不能当作普通缺失降级 |
| `..`、符号链接或 junction 越界 | 整批预检拒绝，包括跳过页的路径检查 |
| 后一待执行页 YAML 重复键/未闭合 | 在第一页写入前整批拒绝；缺字段仍按原例外处理 |
| 标志继承与非法标志 | enhancement 两标志顺序兼容；repair 拒绝 `--no-video`；非法参数整批零写入 |
| 普通/defer 收尾 | 按每页原权限收尾；跳过页/无变化页无日志或片段，无自动 sync |
| 执行中页面被并发修改 | 核对固定身份，安全停止受影响页，其他安全页继续；报告部分失败 |
| LF、CRLF、媒体重复引用与宽度 | 沿用单页字节/顺序/后缀验证；raw 与日志旧前缀不变 |
| 正文丰富但无标准六节 | 以既有正文归纳追加六个标准章节，不能把相近主题当作已有章节 |
| 已有「关联 Wiki」但缺其余五节 | 仅在 EOF 按标准顺序补前五节，原关联节及链接字节不变 |
| 已有部分标准章节 | 只追加缺少的标准章节，不移动或重复旧节，新增节按标准顺序排列 |
| 代码、引用、注释或转义示例含标准标题 | 示例不计入覆盖；缺少的真实标准章节仍须补齐 |
| 缺节缺乏支持证据 | 仍追加该标准标题并简述证据限制，不编造内容或引用 |
| 同一正文直接单页与批量缺 raw 调用 | 标准章节补齐结果一致，均不读取 raw 或媒体 |
| 六个标准章节齐全后的重复调用 | 没有其他必要维护时零写入，不新增重复标签、章节、引用说明、日期、日志或队列片段 |

交付时区分“规则和案例审阅”“只读分派验证”“实际单页写入验收”“既有自动回归”；未运行的项目不得标为通过。
